# java-mini-projects

Сборник учебных мини‑проектов на Java для отработки базовых тем.  
Код о пройденной теме — в своей папке, со своим `README_"наименование темы".md` и своим `main`.

## Структура

- `java-mini-projects\src\loops` — задачи на циклы. Одна из первых тем, с которой я познакомилась на курсе.
- `java-mini-projects\src\arrays` — задачи на массивы. 
- 
- `java-mini-projects\src\final_module"порядковый_номер"` — задачи в конце спринта. Совокупность всех знаний, 
которые я накоприла за 2 недели. 
Мамина гордость, папина радость.

## Как запустить отдельный проект

В IntelliJ IDEA:
1. Открой проект.
2. В окне Project найди нужный класс с `main`.
3. Нажми правой кнопкой → Run `Main.main()`.
